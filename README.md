# Assessing-Machine-Learning-Models-Biasness-in-Predicting-Heart-Attack-Across-Demographics
A fairness audit of Random Forest and Gradient Boosting models predicting heart attack from 2022 CDC BRFSS survey data (246,022 records). Performance was compared across sex, race and age using t-tests and bootstrap CIs, revealing lower recall for women and under-50s despite similar accuracy.
